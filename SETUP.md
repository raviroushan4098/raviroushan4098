# Setup

1. Open your profile repo: github.com/raviroushan4098/raviroushan4098
2. Replace `README.md` and upload the WHOLE `assets/` folder (delete the old assets first so no stale files remain).
   - Easiest on a laptop: unzip, then drag the files into the repo's "Add file > Upload files" page.
   - Or use git: copy the files in, then `git add . && git commit -m "New profile" && git pull --rebase origin main && git push`.
3. Add your photo (optional but recommended):
   - Put a clear photo next to `add_photo.py` and run: `python3 add_photo.py my_photo.jpg`
   - Then upload the updated `assets/hero.svg`.
   - Or send the photo to Claude in chat and ask it to embed it.
4. Pin your 6 best repos on your profile page.
